# Proposal

## Why

Households and small teams want to work on the same list. Sharing a project gives others access without sharing an account.

## What Changes

- Owner invites a user by e-mail; invited users see and edit the project's todos.
- Owner can remove members; members can leave.

Out of scope: roles and permissions beyond owner/member, public links.

## Capabilities

### New Capabilities
- `organisation/sharing`: share a project with other users.
