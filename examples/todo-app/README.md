# Sample: todo app

An OpenSpec context for a small todo app, used to try the workflow, the skill and the dashboard. It contains only
`openspec/`, no application code. State: two changes archived, `add-due-dates` in progress, five drafts in the
backlog, a parking lot with deferred items.

```sh
cd examples/todo-app
node ../../tools/openspec-dashboard/server.mjs
```
